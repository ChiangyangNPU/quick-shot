# 修复记录：macOS 上设置/历史窗口被连带抬到前台

> 文档说明：本文档最初是修复计划，实现过程中按实际反馈做了多轮增补（点击贴图、
> 待办窗口不显示、截图/录屏取消后设置露出、历史窗口点击激活、历史窗口浮动层级
> 压不下去等）。以下内容已按最终实现更新。

## Context

设置/历史窗口打开后被其他应用盖住（沉底）时，以下操作会把它们连带抬到其他应用之上
（仅 macOS，Windows 正常）：

1. **触发截屏 / 录屏 / 长截图**：应用被激活后，窗口随应用整体上浮；截屏/录屏取消后
   露出，滚动截图期间一直挡在截取页面上层
2. **Alt+P 历史贴图**：热键入口激活应用；**点击贴图**同样激活应用
3. **Alt+H 历史窗口**：热键入口激活应用；**点击历史窗口**同样激活应用
4. **右击桌面宠物打开待办窗口**：打开时激活应用（且修复后待办气泡曾一度不显示）

## 根因（两条）

1. **应用激活会抬起全部窗口**（`ClotheslineWindow.cpp:112-117` 注释已记录）：macOS 上
   Qt 的 `raise()`/`activateWindow()` 会经 `QT_MAC_SET_RAISE_PROCESS` 调
   `activateIgnoringOtherApps` 激活整个应用，系统随之把应用**所有窗口**整体抬到其他
   应用之上；**点击非活动应用的窗口**同样会激活应用（系统行为）。Windows 的
   raise/activateWindow 只影响目标窗口本身，故无此问题。
2. **Qt::Tool = NSPanel 浮动层级**（探针程序实测）：Qt 把 `Qt::Tool` 窗口设为
   `NSFloatingWindowLevel(3)`，且会在 `show()` 返回后约 20ms 异步再设一次，
   窗口会一直浮在其他应用的普通窗口之上、点击别处也无法沉底。

## 最终实现

### 1. Utils 新增辅助函数（src/utils/Utils.h、Utils.cpp）

- `showFrontNoActivate(QWidget*)`：`show()` 后——macOS 用 `[NSWindow orderFrontRegardless]`
  把窗口提到所在层级最前但不激活应用；其他平台 `raise()+activateWindow()`（维持 Windows 原行为）。
- `activateIfAppActive(QWidget*)`：macOS 仅当应用已激活时才 `activateWindow()`
  （沿用 ClotheslineWindow 模式）；其他平台无条件激活。
- `clearNSPanelUtilityStyle(QWidget*)`：清除 `NSWindowStyleMaskUtilityWindow`，让
  `Qt::Tool` 的 NSPanel 保持普通窗口标题栏外观。
- `setWindowNormalLevel(QWidget*)`：把窗口层级从浮动(3)改回普通(0)。

### 2. Alt+H 历史窗口

- src/shortcut/ShortcutTypes.cpp：改为 `Utils::showFrontNoActivate(historyWindow)`
  （热键/托盘分发共用，一并覆盖）。
- src/widgets/HistoryWindow.cpp：窗口改为 `Qt::Tool`（NSPanel 非激活面板）——
  点击窗口不再激活应用；清除工具窗口样式位保持原标题栏外观；加
  `WA_MacAlwaysShowToolWindow` 保证切到其他应用时不隐藏。
- `showEvent` 中延迟 50ms 把层级降回普通层级(0)（Qt 会在 show 后异步重置为浮动层级）。

### 3. Alt+P 贴图

- src/capture/SnipScreen.cpp `pinClipboard`：singleShot 内改用 `Utils::showFrontNoActivate`。
- src/widgets/PinWindow.cpp：
  - 构造函数 100ms 定时器 `activateWindow()` → `Utils::activateIfAppActive(this)`；
  - `toggleAll` 恢复分支 → `Utils::showFrontNoActivate(pw)`；
  - 构造时 `Utils::setNSPanelNonActivating(this)`：**点击贴图不再激活应用**。

### 4. 右击宠物 → 待办窗口

- src/pet/DesktopPetManager.cpp `showTodoWindow`：`Utils::showFrontNoActivate(m_todoWindow)` +
  `Utils::activateIfAppActive(m_todoWindow)`。
- src/pet/TodoWindow.cpp：补 `WA_MacAlwaysShowToolWindow`——修复应用未激活时
  右击宠物待办气泡不显示（NSPanel 默认 hidesOnDeactivate）。

### 5. 滚动截图提示条（src/capture/ScrollCaptureSession.cpp）

- `createHintBar()`：提示条设为非激活面板——滚动过程中点击"完成/取消"不激活应用。
- `:273` 的 show/raise/activateWindow/setFocus 保留（会话开始时应用必然已激活，
  提示条需要 Enter/Esc/V/H 键盘）。
- `createFrameOverlay` 去掉 `m_frameOverlay->raise()`（已有 `WA_ShowWithoutActivating`）。

### 6. 截屏/录屏/滚动截图开始时隐藏辅助窗口（仅 macOS，不自动恢复）

- src/capture/SnipScreen.h/.cpp：新增 `setSettingsWindow()` / `setHistoryWindow()` 与
  `QPointer` 成员；`hideAuxiliaryWindowsForCapture()` 在 `startCapture()`（截图/录屏共同
  入口，抓取背景前）与 `startScrollCapture()` 中调用，隐藏可见的设置/历史窗口。
- src/main.cpp：创建设置窗口（`ensureSettingsWindow`）与历史窗口后分别注入指针。
- 不自动恢复是有意行为（用户选择）；Windows 上激活不影响其他窗口层级，该逻辑仅 macOS 生效。

## 已知取舍与限制

- Alt+H/Alt+P 从热键打开时不再激活应用，键盘输入需先点击对应窗口（macOS 标准行为）。
- 截图/录屏/滚动截图开始时设置与历史窗口会被隐藏，结束后不自动恢复，需从托盘重新打开。
- 待办窗口（TodoWindow）需要文字输入，未做成非激活面板：点击它仍会激活应用，
  此时设置窗口可能随之抬起。
- 历史窗口作为 NSPanel 不参与 Cmd+` 窗口轮换与"窗口"菜单。
- 贴图窗口为非激活面板：点击不激活应用，面板可成为 key window 接收键盘。

## 验证

1. CMake 构建（macOS Debug），单元测试全部通过。
2. 手工验证（前置：打开设置窗口 → 点击其他应用使其沉底）：
   - Alt+P：贴图出现在其他应用之上、设置沉底；点击贴图不再把设置带上来；拖动/缩放/双击关闭正常。
   - Alt+H：历史窗口出现、设置沉底；点击历史窗口不激活应用；点击其他位置历史窗口可正常沉底；搜索框点击后可输入。
   - 右击宠物：待办气泡正常显示、设置沉底；点输入框后可输入。
   - 滚动截图：进入后设置/历史窗口隐藏；点提示条"完成/取消"不会把设置带上来；结束后不自动恢复。
   - 截屏/录屏：触发后设置/历史窗口隐藏；取消后不再露出。
3. Windows 回归：各入口行为与修改前一致（辅助函数非 macOS 分支保持原行为）。

QuickShot v0.1.2 —— 滚动截图（长截图）来了（GitHub / Gitee 双端同步发布）

## ✨ 新增

- **滚动截图（长截图）**：选区完成后点工具栏「长截图」按钮，或按 `V`（垂直）/ `H`（水平）进入。手动滚动页面，程序每 150ms 自动抓帧并实时拼接，提示条同步显示已拼接长度；`Enter` 或「完成」生成长图并直接贴图（贴图窗口承载，可继续复制 / 保存 / 标注 / 翻译），`Esc` 或「取消」放弃。拼接采用行指纹投票定位：纯白/大面积留白、固定表头与底栏、重复排版均不干扰对齐，未滚动时不会虚增像素；达到长度上限自动完成并提示
- **GIF 录制**：截图与录屏工具栏均提供 GIF 快捷入口，一键以 GIF 格式开始录制（Windows / Linux；macOS 暂不支持，入口自动隐藏）
- **标注线型**：标注工具支持实线 / 虚线切换，并按工具分别记忆线型偏好

## 🐛 修复

- **录屏控制栏**：隐藏时同步复位录屏按钮选中态——修复取消录制后再次触发录屏，按钮保持高亮但控制栏不显示的问题
- **录屏控制栏**：边距、圆角、分隔符样式与工具栏规范对齐；格式下拉框初始不再被省略为「...」
- **设置窗口**：消除懒加载后首次打开设置页的高度跳变

## 🌐 界面文案

- 界面中的「OCR」统一改为「文字识别」

## 🧪 工程化

- 滚动截图拼接器单元测试（7 个用例 / 26 条断言，含垂直/水平、固定表头底栏、白底留白、重复帧忽略等场景）接入 CI 双平台自动运行
- Gitee Release 附件配额自动清理，发布流程更稳定

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `QuickShot-Release-v0.1.2-Windows-x64.zip` | 解压即用，已含全部依赖 |
| macOS arm64 | `QuickShot-Release-v0.1.2.dmg` | 引导式安装窗口，把 QuickShot 拖入「应用程序」 |

> macOS 未做 Apple 公证：首次打开请**右键 →「打开」**放行；录屏 / 系统录音需在「系统设置 → 隐私与安全性」中授权。
> **升级提示**：通过应用内"检查更新"升级的用户无需任何操作（更新流程自动完成新旧交接）。手动安装时若启动新版提示「QuickShot 已在运行」，请先退出旧版本（托盘图标右键 → 退出）再启动。

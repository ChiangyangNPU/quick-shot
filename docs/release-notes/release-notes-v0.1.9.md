QuickShot v0.1.9 —— 宠物定时推送 · 翻译窗口增强 · 开源许可证切换 GPLv3（GitHub / Gitee 双端同步发布）

## ✨ 新增

- **桌面宠物 · 定时推送**：设置页「宠物 → 定时推送」可按「星期几 + 时间」添加任务并填写网址，到点后宠物做出**吐出网页**的动画，随即用系统默认浏览器打开该网页。任务支持单独启用 / 停用，独立保存在本地（`scheduled_tasks.json`），仅在宠物开启时生效；同一分钟多条任务会依次弹出，不会互相覆盖
- **翻译结果窗口 · 目标语言即时切换**：标题栏新增语言下拉框，切换后立即按新语言重新翻译当前内容（翻译期间显示「翻译中」，完成后回到当前视图模式）；选择与设置页共用同一配置项，两端实时同步
- **翻译结果窗口 · 圆角外观**：窗口改为圆角矩形，四个角由标题栏、原图区、操作栏分别处理，浅色 / 深色主题下边缘都干净

## 🐛 修复

**设置窗口**

- **切到「历史记录」Tab 时滚动条出现时机异常**：macOS 上滚动条要等高度动画快结束才出现；Windows 上则会先闪现再消失。现在切换瞬间即按目标高度判定是否需要滚动条，两端表现一致

**桌面宠物设置**

- **网址输入框未适配深色主题**：深色主题下输入框仍是白底，与同页下拉框、数字框不一致；现按主题配色并补上聚焦高亮与占位符颜色
- **星期复选框与文字重叠**：设置页位于滚动区域内时，样式表的复选框间距不生效，导致方框压住「一 / 二 / 三…」文字。现改为自绘方框与文字，间距固定，点击行为不变

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `QuickShot-Release-v0.1.9-Windows-x64.zip` | 解压即用，已含全部依赖 |
| macOS arm64 | `QuickShot-Release-v0.1.9.dmg` | 引导式安装窗口，把 QuickShot 拖入「应用程序」 |

> macOS 未做 Apple 公证：首次打开请**右键 →「打开」**放行；录屏 / 系统录音需在「系统设置 → 隐私与安全性」中授权。
> **升级提示**：通过应用内"检查更新"升级的用户无需任何操作（更新流程自动完成新旧交接）。手动安装时若启动新版提示「QuickShot 已在运行」，请先退出旧版本（托盘图标右键 → 退出）再启动。

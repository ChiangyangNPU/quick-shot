QuickShot v0.1.3 —— 桌面宠物 & 深色主题（GitHub / Gitee 双端同步发布）

## ✨ 新增

- **桌面宠物**：开启后，截图点击复制、贴图、录屏中点击快照，或复制 / 剪贴电脑中的文字时，图像与文字会以动画飞入宠物口中；点击宠物打开「晾衣绳」，查看最近的截图与复制的文字
  - **晾衣绳窗口**：铺满主屏幕宽度，单击宠物或鼠标移到主屏上边界热区均可弹出 / 收起（一次进入只切换一次，热区内悬停不会反复弹收）；出入场为整体滑动动画——弹出时从屏幕上方滑下「挂入」，收起时向上滑出屏幕；默认挂在屏幕高度 1/10 处，支持拖动移动与边缘调整大小；× 关闭按钮圆心与绳线对齐；双击空白区域隐藏；应用内窗口的点击不会误关闭晾衣绳
  - **悬浮式晾衣绳视觉**：去掉整块半透明底板，绳与卡片直接悬浮在桌面上；卡片带柔和投影（随摆动一起绘制），空历史提示与 × 关闭按钮改为小面积深色托底，任意桌面背景下清晰可读
  - **卡片预览**：悬停放大预览，预览加载原图并支持滚轮缩放；右键菜单可直接复制 / 标注 / 文字识别 / 翻译
  - **16 种外观**：经典组 4 种（小橘猫 / 熊猫 / 企鹅 / 青蛙）+ 十二生肖组 12 种，设置页平铺图标点选即切换；宠物与晾衣绳按屏幕 DPI 自动缩放
- **浅色 / 深色主题一键切换**：设置 → 样式页新增主题下拉框。深色为 HUD 风格（深底白字、半透明按钮），作用于截图 / 录屏工具栏、子工具栏、录屏控制栏、设置 / 历史窗口、托盘菜单与对话框，切换立即生效并持久化；窗口系统标题栏（Windows / macOS）随主题联动，工具栏图标深色下自动染色

## 🐛 修复

- **macOS 窗口常驻**：修复点击其他应用后，桌面宠物、晾衣绳、贴图、投喂飞行动画与卡片悬停预览被系统整体隐藏的问题（macOS 将 `Qt::Tool` 窗口实现为 NSPanel，默认随应用失活隐藏，Windows 无此行为）
- **macOS 前台不打扰**：点击宠物 / 晾衣绳不再把 QuickShot 拉到前台——此前点击宠物会激活应用，被其他应用窗口盖住的窗口（如设置）会跟着冒出来；现在宠物面板不抢焦点，后台应用与既有窗口层级均保持原状
- **翻译隐私确认**：贴图窗口与晾衣绳预览的翻译入口改为异步隐私确认——Windows 弹框改非模态，修复弹框关闭后工具栏无法点击；macOS 修复弹框不可见与整体闪烁；「不再显示」文字适配深浅色主题
- **OCR**：识别结束后统一释放模型，降低常驻内存占用
- **贴图窗口**：非标注模式下 `Esc` 可直接关闭窗口
- **标注撤销 / 重做**：修复拖动标注后再撤销/重做，旧的移动记录错套到其他标注、导致标注位置跳变的问题；修复移动标注后又有橡皮擦 / 马赛克等更新操作时，`Ctrl+Z` 先还原标注位置而非撤销最新笔迹的问题
- **滚动截图**：修复提示条背景未绘制导致文字看不清；完善页脚处理与异常恢复
- **应用内更新**：修复 Windows zip 兜底下载 URL 缺少 `v` 前缀导致下载失败
- **历史记录**：修复缩略图文件名残留 `%2` 占位符
- **深色主题**：复选框勾选标记不再不可见；macOS 复选框恢复原生绘制并修复指示器错位

## 🎨 界面与文案

- 历史记录文本改为白底圆角卡片，与晾衣绳文字卡片风格统一；设置 / 历史窗口选项卡切换的高度动画与滚动条闪烁优化
- 宠物选项卡说明文案开启自动换行，适配各语言长度；macOS 宠物选项卡窗口高度按最终内容宽度估算，消除底部大片空白
- 设置「关于」页 QuickShot 名称字体增大；宠物功能说明六语言补充「复制或剪贴文字」投喂描述

- 清理 MosaicAnnotation / PrecisionSlider 死代码与孤儿翻译键

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `QuickShot-Release-v0.1.3-Windows-x64.zip` | 解压即用，已含全部依赖 |
| macOS arm64 | `QuickShot-Release-v0.1.3.dmg` | 引导式安装窗口，把 QuickShot 拖入「应用程序」 |

> macOS 未做 Apple 公证：首次打开请**右键 →「打开」**放行；录屏 / 系统录音需在「系统设置 → 隐私与安全性」中授权。
> **升级提示**：通过应用内"检查更新"升级的用户无需任何操作（更新流程自动完成新旧交接）。手动安装时若启动新版提示「QuickShot 已在运行」，请先退出旧版本（托盘图标右键 → 退出）再启动。

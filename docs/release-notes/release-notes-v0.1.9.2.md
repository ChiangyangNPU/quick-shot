QuickShot v0.1.9.2 —— macOS 截图辅助窗口闪现修复 + 工具栏图标重绘（GitHub / Gitee 双端同步发布）

## 🐛 修复

- **macOS：OCR / 翻译 / 长截图时设置、历史窗口连带弹出闪现**：截图会话期间只要应用被激活（触发 OCR、翻译的隐私弹框降遮罩、长截图提示条、复制 / 保存 / 贴图 / Esc / 录屏收尾），被其他应用盖住的设置 / 历史窗口会被连带抬出，或已可见的部分瞬间消失，表现为闪现。现在改为「截图开始即隐藏」并精确化隐藏时机：先取冻结截图（含设置 / 历史窗口画面）、再做框选吸附枚举，之后才隐藏辅助窗口——会话全程辅助窗口不可见，所有激活与收尾路径均无连带闪现，且框选吸附自身窗口的能力完整保留

## 🎨 界面

- **重画马赛克与橡皮擦工具图标**：橡皮擦原图标形状不像橡皮擦，改为 lucide 风格斜置橡皮块（倾斜橡皮主体 + 分割线 + 底部桌沿线），一眼可辨；马赛克由均匀宫格改为棋盘格双色块（对角实心 + 对角空心），经典马赛克符号。两者保持 currentColor 描边风格，浅色主题黑色、深色主题自动染白，与工具栏其余图标同一风格家族

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `QuickShot-Release-v0.1.9.2-Windows-x64.zip` | 解压即用，已含全部依赖 |
| macOS arm64 | `QuickShot-Release-v0.1.9.2.dmg` | 引导式安装窗口，把 QuickShot 拖入「应用程序」 |

> macOS 未做 Apple 公证：首次打开请**右键 →「打开」**放行；录屏 / 系统录音需在「系统设置 → 隐私与安全性」中授权。
> **升级提示**：通过应用内"检查更新"升级的用户无需任何操作（更新流程自动完成新旧交接）。手动安装时若启动新版提示「QuickShot 已在运行」，请先退出旧版本（托盘图标右键 → 退出）再启动。

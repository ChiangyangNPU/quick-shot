QuickShot v0.1.9.1 —— 更新下载进度条深浅色适配（GitHub / Gitee 双端同步发布）

## 🐛 修复

- **更新进度条百分比文字未适配主题**：检查更新 / 下载更新时，进度条上的百分比文字未指定颜色，会跟随系统调色板。系统为浅色外观而应用切到深色主题时，黑色数字落在深色轨道上几乎不可读。现在文字显式使用主题文字色，浅色 / 深色主题下都清晰可读
- **浅色主题下进度填充块不可见**：填充色原先取纯白，与白色轨道混在一起看不出进度。现改为半透明的主题强调色，既能看清进度推进，文字落在轨道区或填充区也都有足够对比度

## 🛠️ 其他

- **版本号支持四段形式**（如 `0.1.9.1`）：CI 的版本校验与 macOS / Windows 打包脚本同步放宽版本解析，修补版可直接以四段版本号发布并被应用内「检查更新」正确识别

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `QuickShot-Release-v0.1.9.1-Windows-x64.zip` | 解压即用，已含全部依赖 |
| macOS arm64 | `QuickShot-Release-v0.1.9.1.dmg` | 引导式安装窗口，把 QuickShot 拖入「应用程序」 |

> macOS 未做 Apple 公证：首次打开请**右键 →「打开」**放行；录屏 / 系统录音需在「系统设置 → 隐私与安全性」中授权。
> **升级提示**：通过应用内"检查更新"升级的用户无需任何操作（更新流程自动完成新旧交接）。手动安装时若启动新版提示「QuickShot 已在运行」，请先退出旧版本（托盘图标右键 → 退出）再启动。

QuickShot v0.1.7 —— 宠物大小可调 · 代理下载增强 · 文本标注自动提交（GitHub / Gitee 双端同步发布）

## ✨ 新增

- **桌面宠物显示大小可调**：设置 → 桌面宠物 → 基本新增「大小」调节，支持 1.0x ~ 2.0x（步进 0.1x），默认 1.0x。缩放以宠物底边中点为锚点，宠物在桌面上的“站立点”不会漂移；调整即时生效并持久化（`pet/scale`），下次启动保持；六语言文案同步

## 🐛 修复

**标注**

- **正在编辑的文字标注在导出时丢失**：在文本框中输入后尚未点击别处或切换工具时，直接点击复制、保存、贴图或 OCR/翻译，导出的截图不包含该文字且标注被丢弃。现在这些操作会先自动提交正在编辑的文本再取图；贴图窗口（PinWindow）的复制/保存同样修复
- **Ctrl+C 在文本编辑中无法复制截图**：文本编辑框内 Ctrl+C 原本只交给文本框处理，未选中文字时等于无操作。现在**有选中文本**时仍按原生行为复制文本，**没有选中内容**时提交文本并复制截图

**更新下载**

- **代理环境下下载超时反复切换下载源、安装包偶发不完整**：
  - 超时判定改双档：等待首字节 30 秒，已有数据后断流放宽到 60 秒，日志携带已收/总字节
  - 超时与网络错误优先在**同一渠道**按已落盘偏移 `Range` 续传（单渠道最多 2 次），重试用尽才切换渠道；换渠道同样保留已下载进度
  - 写盘移入独立工作线程，避免同步写盘阻塞事件循环造成超时误报；积压 8MB 时暂停抽取并靠 TCP 反压封顶内存
  - 收尾前抽干 Reply 缓冲再关闭，防止安装包尾部被截断
  - 兼容服务器忽略 `Range`（返回 200）、偏移越界（416）与 3xx 重定向；半截包跨渠道保留，仅取消、全部渠道失败或写盘/校验失败时删除
  - release API 渠道 checksum 为空时，以文件大小精确匹配作为完整性防线

## 🛠️ 技术特性

- 更新模块下载/校验重构：新增独立写盘线程与续传状态机，UI 进度按绝对字节计算不会倒退（详见架构文档 6.18.3）
- 宠物窗口尺寸统一由 `PetWindow::petSize()` 计算（96 逻辑像素 × 屏幕 DPI 系数 × 用户倍数），默认落点、缩放与角标定位共用同一尺寸来源

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `QuickShot-Release-v0.1.7-Windows-x64.zip` | 解压即用，已含全部依赖 |
| macOS arm64 | `QuickShot-Release-v0.1.7.dmg` | 引导式安装窗口，把 QuickShot 拖入「应用程序」 |

> macOS 未做 Apple 公证：首次打开请**右键 →「打开」**放行；录屏 / 系统录音需在「系统设置 → 隐私与安全性」中授权。
> **升级提示**：通过应用内“检查更新”升级的用户无需任何操作（更新流程自动完成新旧交接）。手动安装时若启动新版提示「QuickShot 已在运行」，请先退出旧版本（托盘图标右键 → 退出）再启动。

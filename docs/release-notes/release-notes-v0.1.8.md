QuickShot v0.1.8 —— 滚动截图增强 · 历史记录修复 · macOS 框选改进（GitHub / Gitee 双端同步发布）

## ✨ 新增

- **滚动截图灵敏度可调**：长截图提示条新增灵敏度按钮，在**宽松 / 标准 / 严格**三档间循环切换（快捷键 `S`，跨会话保留）。表格等大片空白内容频繁触发"画面变化过大，已重新对齐"的问题，切到宽松档即可缓解
- **长截图提示条支持"文字/图标"样式**：提示条四个按钮（方向 / 灵敏度 / 完成 / 取消）接入设置页的按钮样式选项，切到图标模式时与一级工具栏形态一致；方向与灵敏度图标随当前状态自动切换（档位由图标本身表达，悬停 tooltip 保留文字说明）

## 🐛 修复

**滚动截图（长截图）**

- **反向滚动的内容被静默丢弃**：水平左滚 / 垂直上滚时新内容从对侧进入，此前被当作"未滚动"丢弃，长图整段缺失。现在支持反向拼接（新内容前置插入），往返滚动不产生重复
- **触控板平滑滚动拼不上**：平滑滚动抓帧时像素多为亚像素位置（系统抗锯齿混合），逐字节精确比对必然失配，表现为连续提示"重新对齐"、长图完全不增长。现在精确匹配失败后改用归一化互相关（NCC）兜底匹配，容忍混合像素
- **横向拼接内容重复错位**：表格等行高一致的周期性内容在匹配时误锁到上一个周期。现在剔除周期性内容的混叠峰后再定位

**历史记录**

- **清空历史后"存储占用"不归零**：SQLite 删除记录只把数据页标记为空闲，文件体积不回收，清空后仍显示数百 KB。现在清空 / 清理过期记录时压缩数据库；库已空则直接删除库文件（下次使用时自动重建），存储占用显示 **0 B**
- **设置页统计不实时**：截图 / 贴图 / 剪贴板新增记录后，设置页"历史记录"Tab 的条数与存储占用不刷新，重启应用才更新。现在记录增删实时同步

**设置窗口**

- **双击标题栏窗口跳位**：固定尺寸的设置窗口双击标题栏会触发系统最大化（Windows）/ 填充（macOS），窗口被挪到屏幕边缘。已禁用相关路径
- **macOS：下拉框弹窗放大成全屏**：设置窗口首次显示后，任何下拉框弹窗都被放大成全屏（必现）。缩放拦截改为按窗口登记，仅作用于设置窗口自身
- **恢复默认样式后下拉框不同步**：样式页"恢复默认"后按钮样式下拉框仍显示"图标"，且重启后图标样式"复活"（残留旧值被回写配置）。已同步显示并修正持久化

**macOS 框选**

- **可框选 QuickShot 自身窗口**：设置 / 历史 / 待办等自身窗口此前被过滤，无法被截图选区吸附，与 Windows 行为不一致。已修复
- **待办气泡等悬浮窗口无法被框选**：悬浮层级的窗口（贴图 / 待办 / 桌宠）被窗口枚举误过滤，选区无法吸附
- 更新下载完成弹窗居中到设置窗口

## 🎨 界面

- 全应用悬浮提示（tooltip）按深浅主题统一配色：修复深色主题下工具栏 tooltip 黑底黑字不可读、长截图提示条 tooltip 白底不随主题的问题
- 长截图提示条快捷键提示改为悬停 tooltip（原按钮内嵌"完成 Enter"等文字常驻显示，显得杂乱）；取消按钮接入与主工具栏 X 一致的红色样式
- 录屏控制栏系统声音 / 麦克风复选框与设置界面样式统一

## 🛠️ 其他

- CI：修复 macOS 构建未限制并发导致低核 runner 触发 swap、构建耗时数小时；Gitee 附件上传失败时输出错误注解（HTTP 码 + 服务端响应），便于定位限流 / 配额 / 令牌问题；文档补充 Gitee 本机补发完整操作说明
- 替换 Qt 6 已弃用的 `Q_OS_MAC` 为 `Q_OS_MACOS`，消除构建警告

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `QuickShot-Release-v0.1.8-Windows-x64.zip` | 解压即用，已含全部依赖 |
| macOS arm64 | `QuickShot-Release-v0.1.8.dmg` | 引导式安装窗口，把 QuickShot 拖入「应用程序」 |

> macOS 未做 Apple 公证：首次打开请**右键 →「打开」**放行；录屏 / 系统录音需在「系统设置 → 隐私与安全性」中授权。
> **升级提示**：通过应用内"检查更新"升级的用户无需任何操作（更新流程自动完成新旧交接）。手动安装时若启动新版提示「QuickShot 已在运行」，请先退出旧版本（托盘图标右键 → 退出）再启动。

QuickShot v0.1.4 —— 桌面宠物陪伴功能上线：待办 · 番茄钟 · 打盹 · 系统状态（GitHub / Gitee 双端同步发布）

## ✨ 新增

- **待办清单与红点提醒**：右击桌面宠物展开待办清单气泡（悬浮在宠物上方，数据仅存本地），未完成/已逾期的待办在宠物头顶显示红点角标，点击角标直达清单
- **番茄钟**：按「工作 N 分钟 → 休息 N 分钟」节奏弹出提醒卡（工作/休息时长可调），计时锚定墙钟，系统休眠也不会打乱节奏；到点后可选择休息、跳过或继续工作
- **待机打盹与摸头**：无互动达到设定分钟数后宠物自动入睡（呼吸 + 浮动动画），任意互动即唤醒；双击摸头原地弹跳，单击已做防抖处理，摸头不会误切晾衣绳
- **系统状态**：开启后实时监控 CPU/内存与电池——占用过高时宠物冒汗提醒，电量过低且未充电时显示电池角标（每次开启监控只提醒一次）
- **装饰与节日彩蛋**：宠物可配戴小红花/草帽/墨镜/皇冠/圣诞帽/南瓜帽/派对帽；圣诞、万圣节、元旦等节日自动戴上应景帽子，可设置生日、当天为宠物庆生
- **自定义宠物外观**：导入本地 PNG/JPG/JPEG/WebP/GIF 作为宠物形象，与内置 16 种样式互斥点选、可随时删除；导入前自动做尺寸/体积预检（超大图拒绝或降采样解码，防止内存暴涨），失败原因按界面语言提示
- **宠物设置页重构为四个分组**：基本（开关）/ 宠物样式（16 种内置外观 + 装饰下拉）/ 自定义宠物（导入与删除）/ 行为（晾衣绳显示/消失方式、待办提醒、番茄钟、打盹、系统状态、节日与生日、重置位置）；晾衣绳显示/消失方式新增下拉选择（点击宠物 / 鼠标移到主屏上边界热区 / 两者皆可）

## 🛠️ 技术特性

- **统一宠物主题色板（PetTheme）**：宠物模块各窗口的颜色集中管理并随应用深浅主题切换，主题切换后宠物、红点角标与晾衣绳立即重绘；晾衣绳色板同步接入（纸卡/麻绳/木夹保持实物配色，高亮描边改用应用强调色）
- **截图保存质量修复**：JPG/JPEG 保存固定最高质量（quality=100，关闭色度子采样），修复截图保存后的边缘红边/偏色；PNG 保持默认压缩不受影响

## 🐛 修复

- **反复开关宠物内存泄漏**：宠物窗口、晾衣绳与番茄钟提醒卡随关闭即时销毁——原先附带永不停止的眨眼定时器与 GIF 全帧缓存滞留内存
- **待办数据防丢失**：待办文件暂时不可读或损坏时拒绝覆盖写回——原先新增一条待办可能清空全部存量；写盘失败显式记录日志
- **提醒卡/气泡被遮挡**：番茄钟提醒卡与待办气泡补齐置顶属性，不再被前台应用窗口盖住
- **打盹与拖动冲突**：打盹中的宠物按下即唤醒并停止浮动动画，拖动不再被动画拉回，松手位置持久化准确
- **低电量提醒可重复**：关闭再打开系统状态监控后，低电量可再次提醒（原先永不复提示）
- **导入失败提示本地化**：自定义素材导入失败原因不再硬编码英文，六语言同步

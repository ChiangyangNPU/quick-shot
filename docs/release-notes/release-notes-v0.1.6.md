QuickShot v0.1.6 —— 翻译窗口分栏改版 · 长截图方向切换 · macOS 窗口层级修复（GitHub / Gitee 双端同步发布）

## ✨ 新增

- **翻译窗口改版为「左图右文」分栏布局**：翻译结果窗口整体重新设计——左侧等比缩放显示截图原图，右侧为可自由选中（鼠标/键盘）、可滚动的译文文本区，拖动中间分栏线可调整两栏宽度；视图模式（仅原文 / 仅译文 / 对照）切换右侧文本内容，默认显示译文。标题栏支持拖动移动窗口、双击关闭，右下角缩放抓手调整大小，ESC 关闭；底部操作栏提供「复制全文」「另存为图片」，右键菜单提供视图切换 / 复制原文 / 复制译文 / 另存为图片 / 关闭；整体跟随应用浅色/深色主题。原「文字选择模式」由右侧常驻可选文本区取代，不再需要手动开关
- **长截图提示条新增滚动方向切换按钮**：「完成」左侧新增方向按钮，点击即在垂直/水平之间切换（`H`/`V` 快捷键保持不变），按钮文案随当前方向刷新；切换后清空已拼接内容，以新方向的首帧重新开始拼接；六语言文案同步
- **滚动截图期间保留选区边框提示**：长截图全程用独立的透明鼠标穿透窗口绘制选区边框，随时确认截取范围；边框绘制在选区外侧，不会被拍进长图
- **新增图片型内置宠物样式「鲸鱼娘」「鲸鱼娘 2」**：内置样式此前均为 QPainter 代码造型，无法呈现复杂插画；新增图片型样式机制，素材打包进程序资源，宠物窗口与设置页预览复用同一等比缩放绘制路径（含咀嚼/投喂张嘴/奖励星星动效）；设置页宠物选项卡新增「特殊样式」分组，六语言同步

## 🐛 修复

**macOS**

- **设置窗口被无关操作连带抬到前台**：点击窗口会激活整个应用，系统随即将应用全部窗口整体抬到其他应用之上，被其他应用盖住的设置窗口跟着冒出来——Alt+H 历史窗口、Alt+P 历史贴图、右击宠物打开待办、滚动截图提示条/参考框、截图/录屏入口、点击贴图等路径均会触发；现在这些入口只把目标窗口提到可见位置、不再激活应用，贴图窗口与滚动提示条改为非激活面板，截图/录屏/滚动截图入口同时隐藏设置窗口避免会话结束后露出
- **历史记录窗口层级异常与连带弹出**：历史窗口改为非激活工具面板（保持普通标题栏外观），点击不再激活应用；并修复 Qt::Tool 窗口被 Qt 异步置为浮动层级后一直浮在其他应用之上无法沉底的问题；截图/录屏触发应用激活时历史窗口不再被连带抬起
- **贴图窗口尺寸变形**：贴图窗口为非激活面板，显示时可能被系统重置为默认 640×480，导致图片被拉伸变形；改为显示后重新应用目标几何，工具栏贴图与 Alt+P 历史贴图两个入口均已修复
- **贴图一级/二级工具栏视觉重叠**：两级工具栏是紧贴的两个顶层窗口，系统投影阴影互相投到对方边缘，看起来像两栏重叠；已关闭窗口投影阴影

**录屏**

- **取消/结束录制后选区状态残留**：录制开始会锁定选区，但取消录制未恢复状态，导致随后切换截图模式时工具栏不出现、只剩选区框；现在取消/结束/出错都会解除锁定
- **录屏三栏高度不齐与跳变**：录屏工具栏、子工具栏与控制栏存在约 3px 高度差，打开控制栏时三栏还会整体变高一次；统一以一级工具栏自然高度为基准，控制栏与子工具栏紧贴堆叠、不再露缝

**截图与标注**

- **标注历史跨会话残留**：截图会话复用同一实例，上一会话的标注会残留在新会话，撤销/重做状态跨会话生效，甚至能撤销回上一会话内容；会话边界现在彻底重置全部标注历史，工具栏状态同步刷新
- **撤销按钮未接入操作按钮注册表**：图标/文字模式切换、语言切换不更新撤销按钮，禁用态样式与其他按钮不一致；已接入统一注册表并补齐禁用态样式，无标注时撤销/重做呈现明确的不可点击外观

**设置**

- **深色主题下部分选项卡按钮不刷新**：常规/历史记录/快捷键三个选项卡切换主题后按钮仍保留旧配色
- **常规/关于页底部留白过大**：窗口高度补偿使用固定值而非选项卡实际高度，多出的空间被页面末端吸收

**视觉**

- **长截图提示条样式与工具栏统一**：底板、文字、按钮改用与工具栏同一套样式并随深浅主题切换，按钮上下留白对称

## 🛠️ 技术特性

- **宠物样式数据拆分**：16 种内置代码造型样式拆分为 `src/pet/pets/` 下的独立源文件（一文件一样式），`PetSpec` 结构迁至 `pets/PetStyles.h`；图片型样式素材打包进 Qt 资源
- **macOS 窗口层级辅助接口**：`Utils` 新增「只提窗不激活应用」「恢复普通窗口层级」等跨平台辅助函数，供历史/贴图/提示条等窗口复用

- 新增设计文档：《液态玻璃主题设计方案》《macOS 设置/历史窗口层级修复方案》

QuickShot v0.1.9.3 —— macOS 晾衣绳卡片悬停预览稳定性修复（GitHub / Gitee 双端同步发布）

## 🐛 修复

- **macOS：晾衣绳卡片悬停预览反复闪烁**：鼠标悬停历史卡片弹出放大预览时，预览一下消失一下显示，循环闪烁（Windows 正常）。根因是 macOS 上预览窗（`Qt::Tool` 透明窗）在显示后会收到"假 leave"——光标实际仍在预览几何内、窗口可见，却被派发 `leaveEvent`，原代码无条件 `hide()`，与晾衣绳 `mouseMove` 的 `showImage` 形成 hide/show 乒乓。现已在 `leaveEvent` 增加几何守卫：光标仍在预览几何内时不隐藏，闪烁消除

- **macOS：点击其他软件后移回卡片，预览不再显示**：修复闪烁后，鼠标点到其他软件（应用失活）再移回晾衣绳卡片，预览照片不出现。根因是 macOS 上应用失活后晾衣绳的 NSPanel 收不到 `mouseMove` / `leaveEvent`，此前靠闪烁修复前反复 `raise()` 激活应用的副作用掩盖了该问题。现已在动画定时器中为失活态补充光标位置轮询：移入卡片弹出预览、移出收起预览，且不把应用抢到前台，与激活态行为完全一致

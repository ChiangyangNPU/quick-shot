QuickShot v0.1.0 —— 首个正式发布版本（GitHub / Gitee 双端同步发布）

## ✨ 核心功能
- **智能截图**：全局快捷键（默认 Alt+Q）、窗口智能吸附、全屏 / 活动窗口快截
- **标注工具**：图形、线条、箭头、文字、马赛克、序号等（支持二级菜单自定义）
- **OCR 文字识别**：中英日韩及多语言混合，基于本地 ONNX Runtime 推理
- **文字翻译**：4 种翻译引擎，基于 OCR 识别结果
- **贴图（Pin）**：截图（含标注）悬浮置顶，支持历史截图循环分页
- **屏幕录制**：区域录制与暂停 / 恢复（Alt+S / Alt+Shift+S）
- **历史记录**：截图自动归档，缩略图快速浏览
- **设置中心**：多语言（中/英/日/韩/繁）、快捷键、保存目录、OCR 语言、GPU 加速

## 📦 安装包
| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `QuickShot-Release-v0.1.0-Windows-x64.zip` | 解压即用，已含全部依赖 |
| macOS arm64 | `QuickShot-Release-v0.1.0.dmg` | 引导式安装窗口，把 QuickShot 拖入「应用程序」 |

> macOS 未做 Apple 公证：首次打开请**右键 →「打开」**放行；录屏 / 系统录音需在「系统设置 → 隐私与安全性」中授权。

两个平台的安装包均来自 GitHub Actions 自动构建（与 Gitee 附件为同一份产物）。

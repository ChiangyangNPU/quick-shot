QuickShot v0.1.1 —— 安全性与体验全面升级（GitHub / Gitee 双端同步发布）

## ✨ 新增

- **单实例互斥**：防止重复启动——双开时第二个实例弹提示后自动退出，避免热键失效、剪贴板记录重复等隐患
- **翻译 API Key 加密存储**：百度 AppId/Key、DeepL Key 不再明文写入配置文件——Windows 使用 DPAPI 用户级加密，macOS 存入系统钥匙串，旧配置在下次使用时自动无损迁移（Linux 暂为明文存储，后续版本接入系统凭据库）
- **macOS 剪贴板文本历史修复**：此前 macOS 后台复制不会进历史（系统限制），现以 1 秒轮询兜底，任意应用中 Ctrl+C 的文字均可正常入历史，并记录真实来源应用

## 🐛 修复

- **macOS 全局热键**：F2–F24 设置后永不触发的错键问题（键码映射表错误）
- **macOS 保存/翻译无响应**：原生保存面板被置顶覆盖层遮挡导致点击无反应的严重问题；保存面板按钮/侧边栏文案随系统语言
- **历史记录**：同一秒内连续截图时，分页可能出现重复/丢条、自动清理可能误删最新记录（排序不稳定）；搜索关键词中的 `%`/`_` 特殊字符按普通字符处理
- **剪贴板来源**：历史记录中"来源应用"改为记录复制时的真实前台应用
- **贴图**：Alt+P 历史翻页范围与"最大保留条数"设置联动（原先固定 1000 条）
- **界面语言**：繁体系统（zh_TW/zh_HK）初始界面不再错误加载简体中文；配置错误提示文案接入多语言
- **设置窗口**：选项卡拆分后快捷键/样式页偶发空白；未打开过设置窗口时工具栏调整的标注默认值不生效
- **更新器**："稍后安装"后退出应用不再误删已下载的安装包
- **翻译**：批量翻译进行中再次触发不再互相打断（提示"翻译进行中"）
- **界面细节**：下拉弹窗锚定与宽度自适应、选区四角手柄对齐、文本框旋转时手柄跟随、录屏工具栏越界钳制等十余项

## ⚡ 性能

- **马赛克涂抹不再卡顿**：重写绘制缓存——涂抹过程中不再随笔迹组数线性增加全屏重采样次数（4K 屏多组笔迹涂抹卡顿的根因），每帧至多一次全帧重采样
- **启动提速**：设置窗口改为首次打开时才加载
- **OCR 降噪提速**：识别热路径的逐框日志降级为调试级别，去除每次识别的全像素统计开销

## 🧪 工程化

- 单元测试基建接入 CI（双平台自动运行）：快捷键键码映射、OCR 解码/预处理、历史库、撤销/重做状态机、选区几何、凭据存储等 12 个测试目标
- 大规模模块化重构：设置窗口六选项卡拆分、录屏编排独立（RecordingSession）、工具栏分层等，行为等价已验证

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| Windows x64 | `QuickShot-Release-v0.1.1-Windows-x64.zip` | 解压即用，已含全部依赖 |
| macOS arm64 | `QuickShot-Release-v0.1.1.dmg` | 引导式安装窗口，把 QuickShot 拖入「应用程序」 |

> macOS 未做 Apple 公证：首次打开请**右键 →「打开」**放行；录屏 / 系统录音需在「系统设置 → 隐私与安全性」中授权。
> **升级提示**：通过应用内"检查更新"升级的用户无需任何操作（更新流程自动完成新旧交接）。手动安装时若启动新版提示「QuickShot 已在运行」，请先退出旧版本（托盘图标右键 → 退出）再启动——这正是单实例保护在防止两个版本同时抢占热键和剪贴板记录。
> **密钥迁移提示**：使用过百度/DeepL 翻译的用户，首次启动新版本后 Key 会自动迁移到系统安全存储（Windows 首次可能弹出 DPAPI 相关确认，属正常现象）。
